# Esafenet 容器格式（逆向笔记）

适用对象：亿赛通（Esafenet / e-Safenet / CDG）文档透明加密落盘后的文件。
**不是** PDF Standard Security，也不是 Office 打开密码。

## 容器布局

```text
+----------------------+  offset 0
| 头 4096 字节          |  明文元数据 + 加密密钥/许可区
+----------------------+  offset 4096
| 正文 ciphertext       |  长度 = 原文件长度
+----------------------+
```

关系：

```text
file_size == 4096 + orig_size
body[i]   == plain[i] XOR pad[i % 512]
```

`pad` 为 512 字节循环密钥流（32 × 16B 块），同一密钥下跨文件复用。

## 头字段（小端）

| 偏移 | 长度 | 含义 | 样本值 |
|------|------|------|--------|
| 0x00 | 8 | 魔数 | `e0 a8 91 e7 d8 f2 05 ac` |
| 0x08 | 2 | 版本 | `02 00` |
| 0x0C | 4 | 头长度 | `00 10 00 00` = 4096 |
| 0x10 | 8 | 原文件长度 | 与明文 size 一致 |
| 0x58 | 32 | 产品名 | ASCII `Esafenet` |
| 0x98 | 4 | 未知字段 | 观测到 `00 0c 00 00` |
| 0x1E0 | 1552 | 密钥/许可区 | 16B 槽；空槽恒为 `5e7d3f612cfb9c8debdbaa6001c8179b`（疑似 ECB(0)） |
| 0x7F0 | 16 | 标记 | `00 01 02 03 04 05 06 07 08 09 0a 0b 1a 0d 2f ae` |
| 0xCC0 | … | 参数 + 封装密钥块 | 含 `05 01 00 10 00 40 00 80` 等 |

密钥/许可区中约 25 个 DATA 槽、其余为空槽填充；不同文件 DATA 槽可能不同，但正文 pad 可相同。

## 加密模式判定（已知明文）

1. `KS = plain XOR body`
2. 检验 `KS[i] == KS[i+512]` 是否覆盖全文件
3. 若成立，则 `pad = KS[:512]`，解密为 `body XOR pad[i%512]`

样本验证：PDF 对 4616 个 512B 块 0 失配；同 pad 直接解出另一份 DOCX。

## 特征串（识别用）

- 魔数 `e0a891e7d8f205ac`（文件前 8 字节）
- 头内 ASCII `Esafenet`（偏移 0x58）
- 去掉 4096 字节后，正文不再含 `%PDF` / `PK` 等明文魔数（被 XOR 打乱）

## 旁路背景（勿写进解密脚本）

透明加密依赖驱动按进程白名单 + 扩展名加解密；弱策略下 `type enc >> out.ext` 也可能得到明文。
正规解密仍应走亿赛通客户端 / 管理端「解密/外发」。本 skill 只覆盖**已知明文对**的脱机还原。
