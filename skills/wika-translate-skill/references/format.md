# WIKA 翻译文件格式规范 (LangStr convention)

## 文件结构

每个语言一个 `.cpp` 文件，内部是一个类的构造函数，把 UI 字符串逐条 `append` 到
名为 `LangStr` 的列表（`QStringList` / `QList` 容器）。中文文件（`FUNC_ChineseSimp.cpp`）
是**主文件（master）**，保存全部词条。

```cpp
#include "FUNC_ChineseSimp.h"
FUNC_ChineseSimp::FUNC_ChineseSimp()
{
    LangStr.clear();
    LangStr.append("控制器总线报警");
    LangStr.append("DM总线报警");
    // ... 其余词条，每条一行 ...
}
```

## 命名约定（assumption，使用前请用户确认）

- 文件名去掉 `.cpp` 即为类名，也是头文件名：
  `FUNC_English.cpp` → 类 `FUNC_English` → 头 `FUNC_English.h`。
- 若实际项目命名不同，请在调用 `init-lang` 时按真实文件名产出，并相应修改
  `#include` 与类名；`add-lang` / `apply-master` 通过正则
  `\b(\w+)::\1\s*\(` 自动定位构造函数，**不依赖文件名**，因此改名副本也能处理。

## 关键不变量：按索引对齐

UI 通过**位置（索引）**取词，因此每个语言文件必须：

- 与中文主文件拥有**相同数量**的 `LangStr.append(...)`；
- 且**顺序完全一致**（第 i 个条目在所有语言里对应同一条 UI 文本）。

任何“新增词条”都必须：先追加到中文主文件末尾，再以相同顺序追加到各语言文件末尾。
绝不能在中间插入，否则索引错位导致串词。

## 词条提取规则（步骤 2）

“有效的中文词条”需同时满足：

1. 位于**双引号字符串字面量**内（如 `"文本"`）；
2. 所在行**不是注释**：
   - 行注释 `//` 之后的内容忽略（但 `//` 出现在字符串内的不忽略）；
   - 块注释 `/* ... */` 跨行的内容忽略；
3. 该词条**未出现在中文主文件中**（即属于新增词条）。

说明：扫描时只认双引号字符串；代码标识符、注释里的中文一律不取。

## 转义处理

- 源文件里个别词条含反斜杠转义，如 `"...摆杆出\(减杆)入仓位置"`。
- 写入时保留反斜杠原样（与源文件风格一致），仅对双引号做 `\"` 转义。
- 翻译时**只翻译中文字符**，保留非中文令牌（如 `B1P`、`Y334A`、`(加杆)`、
  `\(` 等）原样不动。

## 未翻译条目标记

`init-lang` 生成新语言文件时，若某词条没有译文，回退为中文原文并追加
`// UNTRANSLATED` 注释，保证文件可编译且便于人工补译：

```cpp
    LangStr.append("液压油温过高报警");  // UNTRANSLATED
```

## 子命令速查

| 子命令 | 作用 |
|--------|------|
| `scan` | 扫描源文件，输出主文件中不存在的中文词条（JSON 数组） |
| `apply-master` | 把新增中文词条追加到主文件末尾（幂等） |
| `init-lang` | 依据（更新后的）主文件，生成全新的语言 cpp（需全量译文） |
| `add-lang` | 把主文件尾部新增词条（译文）追加到已有语言 cpp（幂等） |
| `check` | 校验各语言 cpp 的条目数与主文件一致 |

详见 `scripts/wika_i18n.py` 的 `--help`。
